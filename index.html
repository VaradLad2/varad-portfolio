How I design

Does this problem even need AI?

Handing a whole engineering drawing to an LLM looks great in a demo. When it misreads 12.5 as 125, nobody can tell a real finding from an invented one. So I split the work up.

  1. Explicit rules get plain code

    If a standard says a feature needs a tolerance, or text cannot go below a minimum height, that is a function with a unit test. It does not need a prompt.

  2. Geometry comes before language

    Parse the drawing first and establish what is actually there: lines, dimensions, symbols and where they sit. The model should not guess at facts that can be measured.

  3. The LLM gets the ambiguous leftovers

    Does this note apply to one view or the whole sheet? What is that vague callout pointing at? This is where context and reasoning genuinely help.

  4. Every finding carries evidence

    A result points to a location on the drawing and the rule it breaks. If an interpretation cannot be tied to something verifiable, it never becomes a result anyone relies on.
